# Jokenpo (Pedra, Papel e Tesoura) em Python
- Projeto de estudos em Python
- Jogo simples de pedra, papel e tesoura contra a máquina, feito em Python
# Como funciona
- O jogador digita sua escolha (pedra, papel ou tesoura)
- A máquina sorteia a dela aleatoriamente
- O jogo mostra o resultado da rodada (vitória do jogador, vitória da máquina ou empate)
- O placar acumulado é exibido a cada rodada
- Ao final de cada rodada, é possível continuar jogando ou encerrar
# Como executar
Precisa ter Python 3 instalado
```bash
python jokenpo.py
```
